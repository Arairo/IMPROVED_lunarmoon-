Hello [name],

We built an open tool that answers, for a given site and date window near the
lunar south pole: how many hours of sunlight, when the long nights fall, how
big the battery needs to be, when you can talk to Earth through the DSN, and
how the flight there changes the arrival date. It uses NASA's 20 m LOLA
terrain and covers the nine Artemis III candidate regions.

Link: https://arairo.github.io/IMPROVED_lunarmoon-/ (no sign-up). There is
also a CSV/GeoTIFF export and a small API if you work in Python.

Would you try it on one real question your team has, and tell us where it
falls short? Ten minutes of your time would shape what we build next.
